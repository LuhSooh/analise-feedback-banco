# 📊 Análise de Feedbacks Bancários

Projeto de estudo voltado à **análise de feedbacks de clientes de uma instituição bancária**, com foco na identificação de sentimentos, problemas recorrentes e oportunidades de melhoria.

## 🎯 Objetivo

Transformar feedbacks de clientes em informações úteis para apoiar a **tomada de decisões**, identificando os principais pontos de fricção na experiência do cliente.

A análise considera diferentes produtos e canais, como:

* 💳 Cartão de crédito
* 📱 Aplicativo
* 💸 Pix
* 💬 Atendimento via chat

## 🔎 O que será analisado

O projeto busca identificar:

* Sentimentos presentes nos feedbacks;
* Principais reclamações dos clientes;
* Problemas recorrentes;
* Produtos ou serviços com maior incidência de problemas;
* Oportunidades de melhoria na experiência do cliente.

## 🧠 Abordagem

A proposta utiliza técnicas de **análise de dados e Inteligência Artificial** para transformar informações textuais não estruturadas em insights que possam auxiliar equipes de Produto e Atendimento.
